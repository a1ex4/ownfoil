Discovery

Let clients find this shop on the local network by themselves, instead of having to enter the address and port.

When running Ownfoil with Docker, discovery only works if the container uses the host network: --network host with docker run, or network_mode: host with Docker compose.
Ownfoil answers discovery requests broadcast on UDP port {{ discovery_port }} with the server configuration, so it can be setup directly.
