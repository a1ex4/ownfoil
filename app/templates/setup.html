Setup Guide

Sphaira

Sphaira has a built-in Ownfoil menu that browses your library by game rather than by file: pick a game, the version and the DLC you want, and it downloads only what it needs, whatever files they are stored in. Downloads resume after a dropped connection, and all artworks are served by Ownfoil itself so your Nintendo Switch never connects to Nintendo's servers.

Discovery

{% if discovery_enabled %}
Discovery is enabled: Sphaira will find this server automatically on your local network.
  1. Connect your Nintendo Switch to the same network as this server
  2. In Sphaira, open (Y) Menu → Menus → Ownfoil
  3. Select Discover local servers, then {{ shop_name }} in the list
    4. {% if current_user.is_authenticated %}
  4. Accept the login prompt, enter {{ current_user.user }} and your password and press Save
    5. {% elif admin_account_created %}
  5. Accept the login prompt, enter your Ownfoil username and password and press Save
    6. {% endif %}

The server is saved with its local address{% if remote_host %} and its remote address {{ remote_host }}, so it keeps working away from home{% endif %}.

{% else %}
Discovery is disabled. Enable it in Services to let Sphaira find this server by itself, instead of typing its address on the console.
{% endif %} {% endif %}

Add the server manually

  1. In Sphaira, open (Y) Menu → Menus → Ownfoil
  2. Open (X) Options → Add server and enter the following details:
    {% if local_address %} {% endif %} {% if remote_host %} {% endif %} {% if admin_account_created %} {% endif %}
    Name: {{ shop_name }}
    Local address: {{ local_address }}:{{ local_port }}
    Remote address: {{ remote_host }}
    User: {{ username }}
    Pass: Password
  3. Press Save.

If there is a single server configured it is opened automatically, otherwise select the server to browse your shop.

{% if local_address and remote_host %}

Sphaira uses the local address at home and falls back to the remote one elsewhere.

Supported Clients

These clients browse the shop from a file list using their own title metadatas, which can differ from what's actually identified by Ownfoil.

{% if tinfoil_enabled %}

Tinfoil

  • HTTP / HTTPS protocol support
  • User authentication
  • Shop browsing with icons and banners
  • Content filtering (games, updates, DLC, XCI) based on URL
  • New games, DLC, Updates, Recommended and XCI sections
  • Compressed content (NSZ and XCZ) support
  • Encrypted shop support
  • Client side Host verification for secure connections
  • Custom welcome message (MOTD)
{% endif %} {% if sphaira_enabled %}

Sphaira (file browser)

  • HTTP / HTTPS protocol support
  • User authentication
  • Directory-based file browsing
  • Content filtering (games, updates, DLC, XCI) based on URL
  • Compressed content (NSZ and XCZ) support
{% endif %} {% if cyberfoil_enabled %}

CyberFoil

  • HTTP / HTTPS protocol support
  • User authentication
  • Shop browsing with icons and Sections (Updates, DLC)
  • Compressed content (NSZ and XCZ) support
  • Client side Host verification for secure connections
  • Custom welcome message (MOTD)
{% endif %}

Local Access is for when your Nintendo Switch and Ownfoil server are on the same network (e.g., both on your home WiFi).
{% if not local_address %}
Unable to determine local server address. Please check your network configuration.
{% else %}
{% if tinfoil_enabled %}
  1. On your Nintendo Switch, open Tinfoil
  2. Navigate to File Browser → New
  3. Enter the following details:
    {% if not shop_public %} {% endif %}
    Protocol: http
    Host: {{ local_address }}
    Port: {{ local_port }}
    Path: / for all content, else one of /base, /update, /dlc, /multi to serve specific content.
    Username: {{ username }}
    Password: Password
    Title: {{ shop_name }} - Local
    Enabled: YES
  4. Press Save to save the location and load the shop
{% endif %} {% if sphaira_enabled %}

  1. On your Nintendo Switch, open Sphaira
  2. Open Menu → Advanced Options → Install options and turn on Enable emummc
  3. Open Menu → Advanced Options → Add / modify mounts → Create New Entry
  4. Enter the following details:
    {% if not shop_public %} {% endif %}
    Type: HTTP
    Name: {{ shop_name }} - Local
    URL: http://{{ local_address }} Add /base, /update, /dlc, /multi to serve specific content.
    Port: {{ local_port }}
    User: {{ username }}
    Pass: Password
  5. Press Save and restart Sphaira
  6. Navigate to FileBrowser → Options → Mount → Select [HTTP] {{ shop_name }} - Local
Opening a file will show a preview of its content. To actually install the file, press Options → Install.
To refresh the shop, simply select another Mount then select back {{ shop_name }}.
{% endif %} {% if cyberfoil_enabled %}

  1. On your Nintendo Switch, open CyberFoil
  2. Open Settings → Shop → Add new shop
  3. Enter the following details:
    {% if not shop_public %} {% endif %}
    Shop title: {{ shop_name }} - Local
    Shop protocol: HTTP
    Host: {{ local_address }}
    Port: {{ local_port }}
    Username: {{ username }}
    Password: Password
  4. Ensure Active shop is set to the correct shop
  5. Press Back to go back to the main menu, and open Install from eShop to browse your shop
{% endif %}
